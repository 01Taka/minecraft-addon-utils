## 導入方法

各アドオンの `package.json` にて、Git タグ `v0.1.0` を指定してインストールします。

```json
{
  "dependencies": {
    "addon-utils": "github:01Taka/minecraft-addon-utils#v0.1.0"
  }
}
```

または：

```bash
pnpm add github:01Taka/minecraft-addon-utils#v0.1.0
```

すべての型・関数・クラス・定数は**パッケージルート（`"addon-utils"`）から直接インポート**します：

```typescript
import {
  getMainhandItem,
  isHoldingItem,
  PlayerStateManager,
  PlayerDirectionResolver,
  calculateVelocityImpulse,
  calculateLiftImpulse,
  MINECRAFT_GRAVITY,
  MINECRAFT_DRAG,
} from "addon-utils";
```

> [!NOTE]
> **サブパスのカプセル化について**:
> 本パッケージは内部のファイル構成の変更（ディレクトリ再編やリファクタリング）による破壊的変更を防止するため、サブパス（`addon-utils/item` 等）への直接アクセスはカプセル化されています。常に `"addon-utils"` ルートからインポートしてください。

## 1. Item / Equipment

プレイヤーの装備状態、アイテム情報、エンチャント、耐久度の安全な取得・判定を提供します。

### 型定義

```typescript
export interface ItemDurability {
  /** 現在の消耗・被ダメージ値（耐久度の減り具合。未使用時は 0） */
  damage: number;
  /** 最大耐久値 */
  maxDurability: number;
}
```

---

### 関数

#### `getEquippableComponent(player: Player): EntityEquippableComponent | undefined`
プレイヤーの装備コンポーネント（`minecraft:equippable`）を取得します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
- **戻り値**: 装備コンポーネント。プレイヤーが無効（切断済み等）な場合や取得失敗時は `undefined`

#### `getEquipmentItem(player: Player, slot: EquipmentSlot): ItemStack | undefined`
指定した装備スロットのアイテムを取得します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
  - `slot: EquipmentSlot`: 取得対象の装備スロット (`EquipmentSlot.Mainhand`, `EquipmentSlot.Offhand`, `EquipmentSlot.Head`, etc.)
- **戻り値**: 装備されている `ItemStack`。未装備またはスロットが空の場合は `undefined`

#### `getMainhandItem(player: Player): ItemStack | undefined`
プレイヤーのメインハンド（利き手）に装備されているアイテムを取得します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
- **戻り値**: メインハンドの `ItemStack`。何も持っていない場合は `undefined`

#### `getOffhandItem(player: Player): ItemStack | undefined`
プレイヤーのオフハンド（逆の手）に装備されているアイテムを取得します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
- **戻り値**: オフハンドの `ItemStack`。何も持っていない場合は `undefined`

#### `isHoldingItem(player: Player, itemTypeId: string, slot?: EquipmentSlot): boolean`
プレイヤーが指定したアイテム種別（typeId）を所持しているか判定します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
  - `itemTypeId: string`: 判定したいアイテムの識別子 (例: `"minecraft:diamond_sword"`, `"custom:throwing_knife"`)
  - `slot?: EquipmentSlot`: 判定対象のスロット。省略した場合はメインハンドまたはオフハンドのいずれかに所持していれば `true` を返します
- **戻り値**: 指定されたスロット（または両手）に対象アイテムを所持している場合は `true`、それ以外は `false`

#### `getEnchantmentLevel(item: ItemStack | undefined, enchantment: string | EnchantmentType): number`
アイテムに付与されている指定エンチャントのレベルを取得します。
- **引数**:
  - `item: ItemStack | undefined`: 対象のアイテム（`undefined` の場合は `0` を返します）
  - `enchantment: string | EnchantmentType`: 取得したいエンチャントのIDまたは `EnchantmentType` (例: `"unbreaking"`, `"sharpness"`, `"efficiency"`)
- **戻り値**: エンチャントのレベル (1以上の整数)。エンチャントが付与されていない、無効、またはアイテムが `undefined` の場合は `0`

#### `getItemDurability(item: ItemStack | undefined): ItemDurability | null`
アイテムの耐久度情報（現在の消耗値と最大耐久値）を取得します。
- **引数**:
  - `item: ItemStack | undefined`: 対象のアイテム（`undefined` の場合は `null` を返します）
- **戻り値**: 耐久度情報 `{ damage, maxDurability }`。耐久度を持たないアイテム、無効なアイテム、または `undefined` の場合は `null`

---

### コード例

```typescript
import { Player, EquipmentSlot } from "@minecraft/server";
import {
  isHoldingItem,
  getMainhandItem,
  getEnchantmentLevel,
  getItemDurability,
} from "addon-utils";

function handlePlayerAttack(player: Player) {
  // 1. メインハンドまたはオフハンドに特定の武器を持っているかチェック
  if (!isHoldingItem(player, "minecraft:netherite_sword")) {
    return;
  }

  // 2. メインハンドのアイテムを取得し、エンチャントと耐久度を確認
  const weapon = getMainhandItem(player);
  const sharpnessLevel = getEnchantmentLevel(weapon, "sharpness");
  const durability = getItemDurability(weapon);

  if (durability) {
    const remaining = durability.maxDurability - durability.damage;
    player.sendMessage(`§7残り耐久値: ${remaining}/${durability.maxDurability} (鋭さ: Lv.${sharpnessLevel})`);
  }
}
```

## 2. Block / Direction

ブロックの面、隣接ブロックの検索、方向列挙値（`Direction`）とベクトル変換を提供します。

### 関数

#### `getAdjacentBlock(block: Block, direction: Direction): Block | undefined`
基準ブロックの指定した面に隣接するブロックを取得します。
- **引数**:
  - `block: Block`: 基準となるブロック
  - `direction: Direction`: 隣接面を調べる方向 (`Direction.Up`, `Direction.Down`, `Direction.North`, `Direction.South`, `Direction.East`, `Direction.West`)
- **戻り値**: 隣接する `Block` オブジェクト。ワールド境界外や未ロードチャンクなど取得不能な場合は `undefined`

#### `getDirectionVector(direction: Direction): Vector3`
Minecraft の方向列挙値（`Direction`）に対応する単位ベクトル（長さ1の `Vector3`）を取得します。
- **引数**:
  - `direction: Direction`: 変換する方向
- **戻り値**: 各軸の単位ベクトル `{ x, y, z }`
  - `Up`: `{ x: 0, y: 1, z: 0 }`
  - `Down`: `{ x: 0, y: -1, z: 0 }`
  - `North`: `{ x: 0, y: 0, z: -1 }`
  - `South`: `{ x: 0, y: 0, z: 1 }`
  - `East`: `{ x: 1, y: 0, z: 0 }`
  - `West`: `{ x: -1, y: 0, z: 0 }`
  - 未知の方向: `{ x: 0, y: 0, z: 0 }`

#### `getOppositeDirection(direction: Direction): Direction`
指定した方向と正反対の方向（`Direction`）を取得します。
- **引数**:
  - `direction: Direction`: 基準となる方向
- **戻り値**: 反対向きの `Direction` (例: `Up` -> `Down`, `North` -> `South`, `East` -> `West`)

---

### コード例

```typescript
import { Block, Direction } from "@minecraft/server";
import { getAdjacentBlock, getDirectionVector, getOppositeDirection } from "addon-utils";

function placeTorchOnWall(targetBlock: Block, hitFace: Direction) {
  // 殴った面の反対方向（壁の奥側）の方向を取得
  const wallDirection = getOppositeDirection(hitFace);

  // 殴った面の手前（隣接ブロック）が空気かどうかを確認
  const placeTargetBlock = getAdjacentBlock(targetBlock, hitFace);
  if (placeTargetBlock && placeTargetBlock.isAir) {
    const normal = getDirectionVector(hitFace);
    // レイキャストや設置処理へ...
  }
}
```

## 3. State Management

### クラス: `PlayerStateManager`
プレイヤー単位のインメモリ状態管理マネージャー。
プレイヤー切断（`world.afterEvents.playerLeave`）時の自動クリーンアップ機能を備え、アドオンの一時データやキャッシュによるメモリリークを防止します。

#### 静的メソッド

#### `static set<T>(playerId: string, key: string, value: T): void`
指定したプレイヤーの状態データを保存します。
- **引数**:
  - `playerId: string`: 対象プレイヤーのID (`player.id`)
  - `key: string`: 管理キー名
  - `value: T`: 保存する任意の値

#### `static get<T>(playerId: string, key: string, defaultValue: T): T`
指定したプレイヤーの状態データを取得します。データが存在しない場合は `defaultValue` を返します。
- **引数**:
  - `playerId: string`: 対象プレイヤーのID (`player.id`)
  - `key: string`: 管理キー名
  - `defaultValue: T`: キーが存在しない、またはプレイヤーが未登録の場合に返すデフォルト値
- **戻り値**: 保存されている値、または `defaultValue`

#### `static has(playerId: string, key: string): boolean`
指定したプレイヤーに特定のキーが保存されているか確認します。
- **引数**:
  - `playerId: string`: 対象プレイヤーのID (`player.id`)
  - `key: string`: 確認するキー名
- **戻り値**: キーが存在する場合は `true`、それ以外は `false`

#### `static delete(playerId: string, key: string): boolean`
指定したプレイヤーの特定のキーのデータを削除します。
- **引数**:
  - `playerId: string`: 対象プレイヤーのID (`player.id`)
  - `key: string`: 削除するキー名
- **戻り値**: データが存在し削除に成功した場合は `true`、キーが存在しなかった場合は `false`

#### `static clearPlayer(playerId: string): boolean`
指定したプレイヤーのすべての状態データをメモリから削除します。
- **引数**:
  - `playerId: string`: 対象プレイヤーのID (`player.id`)
- **戻り値**: プレイヤーのマップが存在し削除された場合は `true`、存在しなかった場合は `false`

#### `static clearAll(): void`
全プレイヤーの全状態データをメモリから完全に削除します。

#### `static registerAutoCleanup(): void`
プレイヤー退出（切断）時に自動でそのプレイヤーのメモリを解放するイベントリスナーを登録します。
アプリケーション起動時（`main.ts`）に一度だけ呼び出してください。二重登録は自動的に防止されます。

---

### コード例（クールダウンやコンボの管理）

```typescript
import { Player, system } from "@minecraft/server";
import { PlayerStateManager } from "addon-utils";

const COOLDOWN_KEY = "skill_dash_last_tick";
const COOLDOWN_TICKS = 40; // 2秒

function tryExecuteDash(player: Player): boolean {
  const currentTick = system.currentTick;
  const lastTick = PlayerStateManager.get<number>(player.id, COOLDOWN_KEY, -9999);

  if (currentTick - lastTick < COOLDOWN_TICKS) {
    const remainSec = ((COOLDOWN_TICKS - (currentTick - lastTick)) / 20).toFixed(1);
    player.sendMessage(`§cクールダウン中: あと ${remainSec} 秒`);
    return false;
  }

  // クールダウン更新
  PlayerStateManager.set(player.id, COOLDOWN_KEY, currentTick);
  player.sendMessage("§aダッシュ発動！");
  return true;
}
```

## 4. Player / Input

権限判定、物理キー入力判定、姿勢対応AABB、および**同一Tick内キャッシュを備えた方向リゾルバー**を提供します。

### 型定義

```typescript
export interface IsPlayerAdminOptions {
  /** 管理者とみなすタグの配列 (デフォルト: ["admin", "op"]) */
  adminTags?: readonly string[];
  /** タグの保持による権限判定を行うか (デフォルト: true) */
  allowTagCheck?: boolean;
  /** 管理者とみなす最小のコマンド権限レベル (デフォルト: CommandPermissionLevel.Any より大きいレベル) */
  minPermissionLevel?: CommandPermissionLevel;
}

export interface DirectionData {
  /** 元の3次元ベクトル */
  vector: Vector3;
  /** XZ平面（水平方向）で正規化された単位ベクトル (yは常に0、長さは1。水平長が0の場合は { x: 0, y: 0, z: 0 }) */
  normalizedXZ: Vector3;
  /** 水平方向(XZ平面)の長さ・ノルム (Math.hypot(x, z)) */
  horizontalLength: number;
}
```

---

### 関数

#### `isPlayerAdmin(player: Player, options?: IsPlayerAdminOptions): boolean`
プレイヤーが管理者権限（OP権限、または指定された管理者タグ）を保持しているかを判定します。
個人プレイ・マルチプレイ共通で安全に動作し、無効なプレイヤー（切断済み等）は常に `false` を返します。
- **引数**:
  - `player: Player`: 判定対象のプレイヤー
  - `options?: IsPlayerAdminOptions`: オプション設定（判定対象タグや権限レベルのカスタマイズ）
- **戻り値**: 管理者権限を保持している場合は `true`、一般プレイヤーまたは無効な場合は `false`

#### `isInputButtonPressed(player: Player, buttonName: string): boolean`
プレイヤーの物理ボタン入力状態を判定します。低バージョンや環境差異に対応し、安全に判定します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
  - `buttonName: string`: 判定したいボタン名 (例: `"Sneak"`, `"Jump"`, `"Sprint"`)
- **戻り値**: 物理キーが押下されている場合は `true`、それ以外は `false`

#### `isSneakButtonPressed(player: Player): boolean`
プレイヤーが物理的にスニーク（シフト）キーを押下しているかを判定します。
1ブロック隙間への進入時や匍匐（クロール）時におけるゲームエンジンの自動スニークによる誤検知を防止します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
- **戻り値**: プレイヤー自身がスニークボタンを押している場合は `true`、それ以外は `false`

#### `getMovementInputAngle(playerOrVector: Player | Vector2): number | null`
プレイヤーの移動入力が正面（前進方向）に対して何ラジアン傾いているかを返します。
Minecraft の raw.x は「左が正(+)、右が負(-)」のため、`-vec.x` で反転して「右を正(+)、左を負(-)」として計算します。
- **引数**:
  - `playerOrVector: Player | Vector2`: Player オブジェクト、または Vector2 (`{ x, y }`)
- **戻り値**: 前進方向を 0 とし、右回りを正(+)、左回りを負(-)としたラジアン値 (`-π` 〜 `+π`)。入力がない（静止状態）の場合は `null`

#### `getPlayerAABB(player: Player): AABB`
プレイヤーの現在のワールド座標系 AABB（バウンディングボックス）を取得します。
通常立ち状態だけでなく、スニーク、水泳、エリトラ滑空などの姿勢変化に伴うヒットボックスの伸縮に対応しています。
- **引数**:
  - `player: Player`: 対象のプレイヤー
- **戻り値**: 最小座標 (min) と最大座標 (max) を含む `AABB`

---

### クラス: `PlayerDirectionResolver`
プレイヤーの移動方向・入力方向・視線方向を解決し、**同一Tick内での重複計算をキャッシュ**するマネージャー。
プレイヤー切断（`world.afterEvents.playerLeave`）時の自動メモリ解放にも対応しています。

#### 静的メソッド
#### `static get(player: Player): PlayerDirectionResolver`
プレイヤーに対応するリゾルバーインスタンスを取得（または新規生成）します。
- **引数**:
  - `player: Player`: 対象のプレイヤー
- **戻り値**: 該当プレイヤーの `PlayerDirectionResolver` インスタンス

#### プロパティ（ゲッター）
- **`movement: DirectionData`**:
  物理的な移動速度（Velocity）情報。同一Tick内ではキャッシュ値を返します。
- **`input: DirectionData`**:
  プレイヤー自身のローカル座標系におけるキー入力方向（一般的な3D系: x=右(+)/左(-), z=前(+)/後(-)）。同一Tick内ではキャッシュ値を返します。
- **`worldInput: DirectionData`**:
  プレイヤーの向いている水平角（Yaw）とキー入力を合成した、実際のワールド空間での進行希望方向。入力がない場合はゼロベクトルを返します。同一Tick内ではキャッシュ値を返します。
- **`view: DirectionData`**:
  プレイヤーの視線方向（ViewDirection）のベクトル情報。同一Tick内ではキャッシュ値を返します。

---

### コード例（入力方向へのダッシュスキル）

```typescript
import { Player } from "@minecraft/server";
import { PlayerDirectionResolver, isSneakButtonPressed, isPlayerAdmin } from "addon-utils";

function handlePlayerSkill(player: Player) {
  // スニークキーを物理的に押下しているか判定
  if (!isSneakButtonPressed(player)) return;

  const resolver = PlayerDirectionResolver.get(player);

  // プレイヤーが現在キー入力しているワールド進行方向を取得
  const worldDir = resolver.worldInput;

  if (worldDir.horizontalLength > 0.1) {
    // 入力方向（正規化ベクトル）に向けてインパルスを付与
    player.applyImpulse({
      x: worldDir.normalizedXZ.x * 1.2,
      y: 0.2,
      z: worldDir.normalizedXZ.z * 1.2,
    });
  } else {
    // キー入力がない場合は視線方向へステップ
    const viewDir = resolver.view;
    player.applyImpulse({
      x: viewDir.normalizedXZ.x * 0.8,
      y: 0.1,
      z: viewDir.normalizedXZ.z * 0.8,
    });
  }
}
```

## 5. Math / Geometry

3次元空間およびXZ平面の幾何計算、AABBバウンディングボックスの距離判定を提供します。

### 型定義

```typescript
export type VectorXZ = { x: number; z: number };

export interface AABB2D {
  min: VectorXZ;
  max: VectorXZ;
}

export interface AABB {
  min: Vector3;
  max: Vector3;
}

export interface AABBDistanceResult {
  /** XZ平面（水平方向）におけるAABBとの最短距離 (ブロック内側の場合は 0) */
  horizontal: number;
  /** Y軸（垂直方向）におけるAABBとの最短距離 (AABBの高さの内側にある場合は 0) */
  vertical: number;
  /** 3次元空間におけるAABBとの最短直線ユークリッド距離 */
  distance: number;
  /** 各軸におけるAABB外側へのはみ出し距離（内側にある軸は 0） */
  delta: { dx: number; dy: number; dz: number };
  /** AABB上面（maxY）を基準とした符号付き垂直距離 (point.y - maxY。正=上面より上, 負=上面より下, 0=一致) */
  verticalTop: number;
  /** AABB下面（minY）を基準とした符号付き垂直距離 (point.y - minY。正=下面より上, 負=下面より下, 0=一致) */
  verticalBottom: number;
}
```

---

### 関数

#### `calculatePointToAABBDistance(point: Vector3, aabb: AABB): AABBDistanceResult`
3次元空間の任意の点とAABBバウンディングボックス間の最短距離を計算します。
- **引数**:
  - `point: Vector3`: 測定対象の点（プレイヤー位置など）
  - `aabb: AABB`: 測定対象のAABB `{ min, max }`
- **戻り値**: 水平最短距離、垂直最短距離、3D直線最短距離、上面/下面からの垂直距離を含む `AABBDistanceResult`

#### `getNearestFaceDirectionVector(vectorXZ: VectorXZ): Vector3`
水平ベクトルから最も近い面方向（東西南北）の単位ベクトル（`Vector3`）を返します。
- **引数**:
  - `vectorXZ: VectorXZ`: 水平方向ベクトル (x, z)
- **戻り値**: 最も近い面方向の単位 `Vector3`（East: `{1,0,0}`, West: `{-1,0,0}`, South: `{0,0,1}`, North: `{0,0,-1}`）。入力がゼロベクトルの場合は `{0,0,0}`。X成分とZ成分の絶対値が等しい場合はX軸成分を優先します

---

### コード例

```typescript
import { Player, Block } from "@minecraft/server";
import { calculatePointToAABBDistance, AABB } from "addon-utils";

function checkPlayerLedgePosition(player: Player, block: Block) {
  const { x, y, z } = block.location;
  const blockAABB: AABB = {
    min: { x, y, z },
    max: { x: x + 1, y: y + 1, z: z + 1 },
  };

  const dist = calculatePointToAABBDistance(player.location, blockAABB);

  // プレイヤーがブロックの上面よりわずかに上（0〜0.3m）にいて、水平距離が 0.5m 以内か判定
  if (dist.verticalTop >= 0 && dist.verticalTop <= 0.3 && dist.horizontal < 0.5) {
    player.sendMessage("§aブロックの縁に立っています");
  }
}
```

## 6. Physics

Minecraft Bedrock の環境物理（重力・空気/水中抗力）を逆算し、**目標速度到達**や**目標高度到達**をピッタリ実現するための純粋物理演算関数を提供します。
関数内部は外部定数に一切依存せず、引数として渡された数値のみで厳密に計算します。

### 定数

```typescript
/** 標準の自由落下重力加速度 (blocks/tick) */
export const MINECRAFT_GRAVITY = 0.08;

/** 各環境における速度維持率 (抗力係数) */
export const MINECRAFT_DRAG = {
  air: { y: 0.98, xz: 0.91 },
  water: { y: 0.8, xz: 0.8 },
  lava: { y: 0.5, xz: 0.5 },
  cobweb: { y: 0.05, xz: 0.25 },
  honey: { y: 0.2, xz: 0.2 },
  ground: { y: 0.98, xz: 0.546 },
  none: { y: 1.0, xz: 1.0 },
} as const;
```

---

### 型定義

```typescript
export interface CalculateVelocityImpulseParams {
  /**
   * 目標とする速度ベクトル (blocks/tick)。
   * 各軸で null または undefined を指定した場合は、その軸の外力制御を行わず現在の慣性・加速度を維持します。
   */
  targetVelocity: { x?: number | null; y?: number | null; z?: number | null };

  /** 現在のエンティティ速度 (player.getVelocity()) */
  currentVelocity: Vector3;

  /** Y軸の速度維持率 (抗力係数: 0.0〜1.0) */
  dragY: number;

  /** XZ軸の速度維持率 (抗力係数: 0.0〜1.0) */
  dragXZ: number;

  /** 1Tickあたりの落下重力加速度 (相殺する場合は正の数値、相殺しない場合は 0) */
  gravity: number;

  /** 経過時間（Tick単位。デフォルト: 1.0） */
  deltaTimeTick?: number;

  /** 追従の鋭さ。null の場合は 1Tick 内で即座に到達（blend = 1.0）。正の数値を指定すると指数減衰補間で滑らかに追従 */
  stiffness?: number | null;

  /** 1Tickあたりに加算できる最大速度変化量（リミッター） */
  maxAcceleration?: number;
}

export interface LiftPhysicsEnvironment {
  /** 1Tickあたりの自由落下重力加速度 (blocks/tick。通常 0.08) */
  gravity: number;
  /** Y軸の速度維持率 (抗力係数。空中は通常 0.98) */
  dragY: number;
}

export interface LiftImpulseResult {
  /** entity.applyImpulse() に直接渡すインパルスベクトル (X, Z は 0) */
  impulse: Vector3;
  /** 最高到達点（目標高度）に達するまでの経過Tick数 (整数) */
  ticksToApex: number;
  /** 最高到達点に達するまでの所要秒数 (ticksToApex / 20) */
  timeToApexSeconds: number;
  /** 逆算された垂直初速度 v0 (blocks/tick) */
  initialVelocityY: number;
}
```

---

### 関数

#### `calculateVelocityImpulse(params: CalculateVelocityImpulseParams): Vector3`
環境の物理特性（抗力・重力）を逆算し、目標速度に到達するためにエンティティへ加えるべきインパルスベクトルを計算します。
外部の定数やデフォルト値には一切依存せず、引数として渡された数値のみに基づいて計算する純粋関数です。
- **引数**:
  - `params: CalculateVelocityImpulseParams`: 速度目標、現在速度、環境物理定数（dragY, dragXZ, gravity）を含む計算パラメータ
- **戻り値**: `entity.applyImpulse()` に渡すためのインパルスベクトル (`Vector3`)

#### `calculateLiftImpulse(targetHeight: number, currentVelocity: Vector3, environment: LiftPhysicsEnvironment): LiftImpulseResult`
指定したブロック数分浮き上がるのに必要な垂直インパルスと、最高点到達までの所要時間を精密に計算します。
ゲームエンジンの離散物理（重力と抗力）を二分探索シミュレーションで逆算するため、非線形な減衰下でも目標高度ピッタリで静止・降下に転じます。
- **引数**:
  - `targetHeight: number`: 浮き上がりたいブロック数・高度差 (H > 0)
  - `currentVelocity: Vector3`: 現在のエンティティのベロシティ (`player.getVelocity()`)
  - `environment: LiftPhysicsEnvironment`: 物理環境設定 (`gravity`, `dragY`)
- **戻り値**: `applyImpulse` に渡すインパルスおよび最高点到達Tick数を含む `LiftImpulseResult`

---

### コード例

#### 1. フックショットや突進スキルでの目標速度制御
```typescript
import { Player } from "@minecraft/server";
import {
  calculateVelocityImpulse,
  MINECRAFT_GRAVITY,
  MINECRAFT_DRAG,
} from "addon-utils";

function pullPlayerTowardsTarget(player: Player, targetSpeedX: number, targetSpeedZ: number) {
  // 水平方向は目標速度に追従させつつ、落下重力を相殺して高度を維持
  const impulse = calculateVelocityImpulse({
    targetVelocity: {
      x: targetSpeedX,
      y: 0, // Y=0 でホバリング維持
      z: targetSpeedZ,
    },
    currentVelocity: player.getVelocity(),
    gravity: MINECRAFT_GRAVITY, // 0.08
    dragY: MINECRAFT_DRAG.air.y, // 0.98
    dragXZ: MINECRAFT_DRAG.air.xz, // 0.91
    stiffness: 8.0, // 滑らかに加速追従
    maxAcceleration: 0.5, // 急加速防止リミッター
  });

  player.applyImpulse(impulse);
}
```

#### 2. オートジャンプ / 段差越え（目標高度への精密跳躍）
```typescript
import { Player, system } from "@minecraft/server";
import {
  calculateLiftImpulse,
  MINECRAFT_GRAVITY,
  MINECRAFT_DRAG,
} from "addon-utils";

function performStepJump(player: Player, stepHeightBlocks: number = 1.2) {
  // 指定した段差（1.2ブロック）ちょうど飛び上がるインパルスを計算
  const { impulse, ticksToApex } = calculateLiftImpulse(
    stepHeightBlocks,
    player.getVelocity(),
    { gravity: MINECRAFT_GRAVITY, dragY: MINECRAFT_DRAG.air.y }
  );

  player.applyImpulse(impulse);

  // 最高到達点に達した瞬間にパーティクルを発生させる
  system.runTimeout(() => {
    if (player.isValid) {
      player.dimension.spawnParticle("minecraft:wind_explosion_emitter", player.location);
    }
  }, ticksToApex);
}
```

## AI向け実装ガイドライン & ベストプラクティス

1. **メモリ解放の原則**:
   - `PlayerStateManager` を利用するアドオンでは、必ずエントリーポイント（`main.ts`）の初期化ルーチンで `PlayerStateManager.registerAutoCleanup()` を一度だけ呼び出してください。
2. **方向解決の原則**:
   - プレイヤーの入力や視線方向を参照する場合、直接 `player.inputInfo` や三角関数を手書きせず、必ず [`PlayerDirectionResolver.get(player)`](#クラス-playerdirectionresolver) を使用してください。同一Tick内キャッシュが効くため、複数モジュールから呼ばれてもパフォーマンスを損ないません。
3. **物理定数の注入原則**:
   - `calculateVelocityImpulse` や `calculateLiftImpulse` を呼び出す際は、暗黙の数値をベタ書きせず、`MINECRAFT_GRAVITY` や `MINECRAFT_DRAG.air` 等の定数オブジェクトからプロパティを渡してください。カスタム環境（水中や低重力）の場合は、その環境に応じた定数や数値を明示的に渡してください。
4. **目標速度制御で一部の軸を維持したい場合**:
   - `calculateVelocityImpulse` の `targetVelocity` において、制御したくない軸（例えばY軸の落下は自然落下に任せたい場合）には `y: null` または `y: undefined` を指定してください。
